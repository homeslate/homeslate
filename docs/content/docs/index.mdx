# Homeslate

Public MIT packages and a reference self-host app. The managed hosted product (Netlify + Neon) lives in the private [homeslate-hosted](https://github.com/homeslate/homeslate-hosted) repository.

## What this repo is

- npm packages published as `@homeslate/*`
- A clone-and-run reference host (`apps/reference`) with no accounts, Stripe, or quotas
