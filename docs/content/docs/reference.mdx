# Reference app

Clone-and-run editor + kiosk for a single local machine. Requires **Node 22.13+**.

There are no accounts, Stripe, or quotas. Persistence is a sqlite file under `apps/reference/data`.

The reference app is a thin consumer of the published packages:
[`@homeslate/server`](/docs/packages/server) runs the API and
[`@homeslate/host-react`](/docs/packages/host-react) mounts the routed web shell.
If you would rather depend on the packages from your own app instead of cloning
this repo, see [Self-hosting](/docs/self-hosting).

## Run

From the repository root:

```bash
vp install
vp run dev:reference
```

Open [http://127.0.0.1:5174](http://127.0.0.1:5174). Vite proxies `/api` to the Hono server on port 8787. Opening the API port redirects there.

In dev the Hono server serves `/api` only, and Vite serves the UI. Both run
against `packages/*/src`: editing a package hot-reloads the UI and restarts the
API. Optional API settings go in `apps/reference/.env` (copy `.env.example`).
Restart the dev command after changing that file.

For a production static-serving setup, run it as a container — see
[`CONTAINER.md`](https://github.com/homeslate/homeslate/blob/main/CONTAINER.md).

## Typecheck

The reference app builds on its own tsconfig solution (Node libs for `src/server`, DOM libs for `src/web`) and is deliberately outside the package `vp run build`.

## Optional Google Calendar

Set these in the API process if you want calendar widgets to sign in:

```bash
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
```

The OAuth callback is `http://127.0.0.1:5174/api/google/callback` (Vite proxies `/api` to the Hono server). Without these variables the editor and kiosk still run; calendar widgets stay empty.
